## Inventory Fields

- `Page`: PDF page number in `Rules_Color_300DPI.pdf`.
- `Area`: working rule area from `Rules_v2.md`.
- `Region`: coarse page region used for traceability.
- `Type`: diagram, table, or grouped visual example.
- `File`: relative PNG path.
- `Alt text`: Markdown alt text.
- `Suggested width`: recommended Markdown display width.
- `Summary`: short source-backed description of what the crop demonstrates.
- `Status`: `cropped`, `no-focused-crop`, `needs-follow-up-crop`, or `pending`.
